# FitTrack Food Import Setup Guide

This guide explains how to:
- fetch 50 foods with direct image URLs from OpenFoodFacts,
- export them to JSON,
- generate SQL insertion scripts,
- create only the Food Database tables for Member 4,
- and seed only food data.

## What Is Already Implemented

Updated importer:
- importation/import_foods.py

Generated/maintained SQL files:
- sql/schema.sql
- sql/foods_seed_from_openfoodfacts.sql (generated by importer)

Generated JSON file:
- db/foods_export.json (generated by importer)

## 1) Prerequisites

- Python 3.10+
- Virtual environment with dependencies installed from importation/requirements.txt
- Supabase project (if you want DB import mode)

## 2) Environment Variables

Create/update .env at the project root with at least:

SUPABASE_DB_URL=postgresql://postgres:<password>@db.<project-ref>.supabase.co:5432/postgres
OPENFOODFACTS_USER_AGENT="FitTrackFoodImporter/1.0 (Fitness Tracker data sync)"
RUN_MODE=export
TARGET_COUNT=50
MAX_PER_TERM=50
EXPORT_JSON_PATH=db/foods_export.json
EXPORT_SQL_PATH=sql/foods_seed_from_openfoodfacts.sql
IMAGE_MODE=direct
SUPABASE_DB_HOST=db.<project-ref>.supabase.co
SUPABASE_DB_PORT=5432
SUPABASE_DB_NAME=postgres
SUPABASE_DB_USER=postgres
SUPABASE_DB_PASSWORD=<password>
SUPABASE_DB_SSLMODE=require
SUPABASE_POOLER_HOST=aws-0-eu-west-2.pooler.supabase.com
SUPABASE_POOLER_PORT=6543
SUPABASE_POOLER_DB_NAME=postgres
SUPABASE_POOLER_USER=postgres.<project-ref>
SUPABASE_POOLER_PASSWORD=<password>
SUPABASE_POOLER_SSLMODE=require

Notes:
- RUN_MODE=export: no DB write; generates JSON + SQL files.
- RUN_MODE=db: writes to DB too (requires SUPABASE_DB_URL).
- MAX_PER_TERM controls the maximum number of foods collected per search term.
- Direct host/port 5432 is primary; pooler (eu-west-2, port 6543) is fallback only.
- In export mode, importer forces direct image URLs.

## 3) Create Database Tables (Member 4 Scope)

Run sql/schema.sql in Supabase SQL Editor or via migration.

This creates only the `public.foods` table and its related type/index/trigger objects.

## 4) Generate Food JSON + Food SQL (50 Rows)

From project root:

Windows PowerShell:

c:/Work/Fitness_Tracker/.venv/Scripts/python.exe c:/Work/Fitness_Tracker/importation/import_foods.py

Result files:
- db/foods_export.json
- sql/foods_seed_from_openfoodfacts.sql

## 5) Insert/Upsert Foods into DB

Run:
- sql/foods_seed_from_openfoodfacts.sql

The script is generated with safe upsert logic:
- rows with source_product_id use conflict on (source, source_product_id)
- rows without source_product_id use conflict on (lower(name), category, lower(serving))

## 6) Optional: Direct DB Upsert from Python

Set:
- RUN_MODE=db

Then run importer again. It will:
- export JSON + SQL
- upsert to DB in the same run

## 7) Troubleshooting

- 403/503 from OpenFoodFacts:
  - keep OPENFOODFACTS_USER_AGENT set,
  - rerun (upstream is occasionally unstable).

- relation public.foods does not exist:
  - apply sql/schema.sql first.

- wrong environment values in terminal:
  - ensure VS Code setting python.terminal.useEnvFile is true,
  - open a fresh terminal.

## 8) Recommended Run Order (Member 4)

1. Apply sql/schema.sql
2. Run importation/import_foods.py in export mode
3. Apply sql/foods_seed_from_openfoodfacts.sql
4. Verify in food.php UI
